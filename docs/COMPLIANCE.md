# Compliance & authorised use

MatchCast is built for **your own** sports production: a camera feed, an
encoder, or a licensed/authorised contribution feed that you have the right to
retransmit, plus scoring data you are allowed to broadcast.

## What this project does

* Accepts an input you configure: your own RTMP/SRT/HLS encoder, a local video
  file, a capture device, or a locally generated demo clip.
* Adds your own graphics, scoreboard, commentary and TTS audio.
* Sends the result to **your** YouTube Live endpoint using **your** stream key.

## What this project deliberately does NOT do

There is no code, and there must never be code, for:

* Downloading, ripping or capturing video from YouTube or any other platform.
* Removing, bypassing or defeating DRM or any access control.
* Evading, confusing or disabling copyright detection (Content ID, fingerprinting,
  watermarking) or any platform restriction.
* Rebroadcasting another broadcaster's feed without permission.
* Removing or obscuring another broadcaster's logo/watermark (that is a
  trademark and signal-integrity violation).
* Circumventing geo-blocking, paywalls or account restrictions.

If you need a feed, obtain it from the rights holder: a licence, a written
permission, your own cameras, or an open/public-domain source.

## Enforcement built into the product

| Control | Where |
| --- | --- |
| Stream start is refused unless the operator attests that they hold the rights to the source | `backend/src/services/streamService.ts` → `startStream()` returns **403** |
| The attestation (who/what/when + optional note) is stored with the input and listed in the rights register | `GET /api/system/authorized-sources`, `Settings.input` |
| Input URLs are validated (`rtmp://`, `rtmps://`, `srt://`, `http(s)://`, `file://`, or a local path) | `shared/src/schemas.ts` → `streamInputSchema` |
| The stream key is read from the environment only, masked in logs and never returned by any API | `stream-worker/src/core/config.ts` (`maskTarget`, `redactStreamKey`), `GET /api/stream/output` |
| Background music is opt-in with an explicit "only with permission" warning; nothing is bundled | `AudioMixer` + Streaming page |
| The demo clip is generated locally (synthetic, no third-party content) | `scripts/make-demo-asset.sh` |

## Audio & music

Commentary and TTS are generated by the system. Background music is **your**
responsibility: only upload a track you have licensed for broadcast, or leave
the background bus at zero. The dashboard says so next to the control.

## Data

Score/player data must come from a source you are allowed to publish (your own
scorers, a licensed provider, or the demo data). Names and team logos you upload
must be yours or licensed.

## Reporting

If you find a feature here that could be abused to infringe rights, treat it as a
security bug and remove it — this project is meant for authorised broadcasts only.
